# 4-bit-CPU
A simple 4-bit CPU designed and implemented in Logisim-Evolution that is capable of performing basic arithmetic and memory instructions. It includes a Python assembler that translates the assembly language to executable images.

# Architecture
The main components of the CPU are:
- 4 general registers (X0, X1, X2, X3)
- ALU
- RAM (Instruction memory and data memory)
- Program Counter (PC)
- Clock

Instructions:
- ADD
- SUB
- LDR
- STR
